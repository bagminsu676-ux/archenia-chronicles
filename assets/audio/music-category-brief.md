# 카테고리별 음악 제작 시트

메인 테마와 같은 판타지 세계의 음악으로 들리되, 모든 장면을 같은 정서로 덮지 않도록 9개 카테고리로 구분합니다. 각 카테고리에는 기본 루프와 변주 루프를 하나씩 둡니다. 실제 이벤트 카테고리 키는 `CATEGORY_MARKS`와 `MUSIC_TRACKS`에 연결되어 있습니다.

권장 공통 규격: 50–90초, 루프 시작과 끝이 자연스럽게 연결, 끝에서 페이드아웃하지 않기, 메인 테마의 3–5음 운명 모티프는 필요할 때만 변형해 사용. 장면 전환은 1–2초 크로스페이드 기준. 이 규격은 초안이며 제작 도구 제한에 맞게 조정해도 됩니다.

|---|---|---|---|
| `family` / 가족 | 식사, 형제 다툼, 빚, 자녀와의 순간 | 난롯가처럼 따뜻하고 익숙한 선율. 현악·피아노 또는 목관의 작은 대화 | 가족 갈등·부재·화해. 같은 선율을 낮은 음역과 느린 호흡으로 변형 |

## 파일명 제안

`<키>-<장면>.mp3` 형식을 권장합니다. 예: `family-home.mp3`, `family-reconciliation.mp3`, `war-march.mp3`, `war-aftermath.mp3`. 파일이 준비되면 `MUSIC_TRACKS` 배열의 두 경로에 연결해 각 카테고리에서 선택하도록 합니다.

각 카테고리에는 설명과 어울리는 고유한 멜로디가 필요합니다. 메인 테마와 같은 세계의 정체성은 음색·화성·리듬의 어휘로 유지하고, 특정 기존 곡의 알아볼 수 있는 멜로디나 편곡을 복제하지 않습니다.
